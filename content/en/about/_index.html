THE OMD STORY

A shared foundation.
Room to keep building.

01 / THE BEGINNING

Open from the start

The Open Monitoring Distribution began in 2010 as a collaboration between several companies, with a shared goal: bring useful monitoring tools together in one installation package.

02 / OUR OWN PATH

OMD Labs Edition

We later created our own fork, OMD Labs Edition. It gives us the freedom to introduce new features quickly and combine tools from the Naemon, Nagios and Prometheus ecosystems.

03 / ALWAYS MOVING

Built, tested, shared

Nightly packages keep development accessible, with extensive tests as part of the build. Stable versions follow roughly twice a year, bringing those improvements into a regular release.

MORE THAN A COLLECTION OF TOOLS

OMD bundles popular third-party projects alongside software written by our own team. A single installation package brings those tools together, so you can spend more time monitoring and less time assembling your stack.
