🎉 SNClient v1.00 is out.

We're moving past the 0.x line because the agent has been stable in production
for a while, and we don't expect breaking changes from here on. The feature set
is solid enough that we can now commit to the API and behaviour staying
compatible for the foreseeable future.

### Breaking Changes

* none

### Features

* add check_multi: execute multiple sub-checks and evaluate the overall result

### Changed

* check_dns: resend lost packets and use the timeout and attempts settings of the resolv.conf
* check_service: add wildcard support for exclude argument
* check_drivesize: add support for hidden shares
* check_process: make parent pid (ppid) available
* check_snclient: add support for check_snclient (formerly check_nsc_web)
* exporter_exporter: fix leaking secrets on /list
* exporter_exporter: do not forward secrets
* exporter: fix goroutine leak in memory watcher
* check_tcp: add read cap of 10MB when reading from remote sockets
* check_ssh: add read cap of 10MB when reading from remote sockets
* check_eventlog: add event-codes argument for the WMI query
* check_eventlog: use event id filter conditions in the WMI query
* check_wmi: support WMI namespace
* check_wmi: add optional worker pool so longer queries do not block other wmi queries
* update golang build chain to 1.27.2

### Bugfixes

* fix remaining zombie processes after automatic updates
