A new version of SNClient was released.

### Breaking Changes

* add semicolon to default nasty characters

### Features

* check_tasksched: improve performance
* check_drivesize: allow specifying drive with trailing slash

### Changed

* check_service: fix typo in output
* move count metrics to front
* update golang build chain to 1.26.4

### Bugfixes

* fix running external scripts with sudo (#388)
* fix rpm installation not creating required snclient user during update (#380)
* fix logfile ownership after upgrade (#380)
* check_files: fix max-depth was ignored when using forward slashes or double backslashes
* rpm: fix setup snclient during update from previous packages
