A new version of SNClient was released. The 1.01 is the first release after the
1.0 and contains minor improvements and support for the ppc64le architecture.
It also updates the windows exporter to the latest upstream release. It builds
against the current golang version 1.27.3.

<!--more-->

### Breaking Changes

* none

### Features

* add ppc64le rpm/deb builds

### Changed

* support multiline external commands and check_multi config
* check_multi: fix aggregating child performance data with the command tag prefix
* check_multi: support config variables with defaults and required values
* check_eventlog: translate event type and source filter conditions into the WMI query
* check_uptime: fix display glitch when uptime is exactly 3 weeks
* check_http: add -P/--post to send request data
* windows exporter: update to 0.32.0
* update golang build chain to 1.27.3
