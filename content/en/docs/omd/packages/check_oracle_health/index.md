|Get version:|check_oracle_health -V|

check_oracle_health is a plugin used to monitor various parameters of an Oracle database server. The plugin is bundled with the Perl module DBD::Oracle.  The Oracle Instant Client must be installed separately; it cannot be bundled with OMD. (Support contract customers with a valid Oracle license get a complete build of OMD-Labs)
